# RDQ 需求規格：四年級教學儀表板（示範課）

## 一句話任務
建立一個 GitHub Pages 數位教學儀表板，讓四年級上學期任何領域的一堂 40 分鐘課都能跑完「引起動機→重點解析→練習」三環節。

## ✅ 已確認
- 每堂課固定三環節：引起動機（影片 10 分）→ 課本重點解析（15 分）→ 練習（15 分）（Ⅰ）
- 版本綁定：國語＝翰林四上、數學＝南一四上、社會＝康軒四上（Ⅰ）
- 影片來源：均一、因材網、各領域版本 YouTube、電子書相關影片，以連結清單提供（Ⅰ）
- 教室環境：投影＋穩定網路＋學生每人有平板（Ⅲ）
- 產出形態：數位儀表板（網頁），每課一頁、含計時器與連結，上課投影用（Ⅲ）
- 技術：GitHub Pages 部署，發網址、任何裝置可開（Ⅲ）
- 範圍：各領域第 1 課/單元示範（國語翰林四上第1課〈美麗島〉、數學南一四上第1單元一億以內的數、社會康軒四上第1課家鄉在哪裡）（Ⅲ）
- Canva 心智圖：學生平板自製（需 Canva 教育版帳號）（Ⅲ）
- 練習環節含：課本練習題、小白板問答（團隊討論）、Canva 心智圖、附件、生字練習（Ⅰ）
